# 確定申告支援ツール(kakuteishinnkoku)

日本の個人向け確定申告を支援するセルフホスト型Webアプリ。
暗号資産・株式等投資の損益計算と、マネーフォワード MEからのデータ取り込みに対応する。

このリポジトリは「ルーティンごとにブラッシュアップする」開発方針で育てている。
1回のセッションで全部を作り切るのではなく、都度機能を積み増していく。
現在の到達点と次にやるべきことは、このREADME末尾の「ロードマップ」を参照。

## 技術スタック

- Next.js 16 (App Router, Server Actions) + TypeScript
- Tailwind CSS v4
- Prisma 6 + SQLite(ローカルファイルDB。個人利用前提でクラウドDBは使わない)
- decimal.js(金額計算を浮動小数点誤差なく行うため、円建て金額は全てDecimalで扱う)
- Vitest(計算ロジックのユニットテスト)

## 機能(現時点)

### 0. 前年繰越残高(期首残高) — `src/lib/openingBalance.ts`

複数年にまたがって暗号資産・株式等を保有している場合、総平均法・移動平均法の
計算にはその年の期首時点の保有数量と取得価額合計が必要になる。`/import`
ページの「期首残高(前年からの繰越)」セクションから、銘柄ごとに期首残高を
手入力できるほか、「前年の期末残高から自動で繰り越す」ボタンで前年分の
計算結果(期末残高)をそのまま当年の期首残高として一括登録できる
(既に登録済みの銘柄は上書きしない)。NISA口座分は課税口座と別ロットとして
別途登録する。

### 1. 暗号資産(仮想通貨)の損益計算 — `src/lib/crypto/`

国税庁の「暗号資産に関する税務上の取扱いについて(FAQ)」に基づき雑所得を計算する。
購入・売却・暗号資産同士の交換(TRADE_IN/TRADE_OUT)・マイニング等の受取
(INCOME)・暗号資産建て手数料(FEE)に対応。

評価方法は**総平均法**(届出が無い場合の法定算出方法。その年の期首残高と
年間取得分を合算した加重平均単価を、その年の全ての譲渡に適用する)と
**移動平均法**(税務署への届出により選択可能。取得の都度平均単価を更新し、
譲渡時点の平均単価を取得費とする)のいずれかを、課税年度ごとにダッシュボードから
選択できる(`TaxYear.cryptoCostMethod`)。移動平均法を選ぶ場合は各取引の取引日時
(tradedAt)が計算に必須になる。

暗号資産取引所(bitFlyer・Coincheck・GMOコイン等)の「取引履歴」CSVも
`src/lib/crypto/exchangeCsv.ts` から取り込める。取引所ごとに専用パーサーを
用意するのではなく、日時・銘柄ペア・売買種別・数量・単価(または合計金額)・
手数料という共通項目に対して、よく使われる列見出し表記をエイリアスとして
幅広く登録する汎用パーサーとして実装している。現状は円建ての現物売買
(買い/売り)のみに対応しており、暗号資産同士の交換やマイニング等の受取は
CSVからは取り込めない(手入力で対応する)。

### 2. 株式・投資信託等の譲渡損益計算 — `src/lib/investment/`

所得税法施行令118条に基づく「総平均法に準ずる方法」(実務上の移動平均法)で
取得費を計算し、譲渡所得(申告分離課税)を算出する。NISA口座は課税口座と
別ロットとして扱い、非課税の参考値として分離表示する。配当等は損益計算とは
別に集計する。

### 3. マネーフォワード ME 連携 — `src/lib/moneyforward/`

マネーフォワード MEの「家計簿」CSVエクスポートを取り込める。ヘッダー名で
カラムを特定するため列順の変更に強く、1行の解析に失敗しても
(不正な日付・金額など)その行だけスキップして処理を継続する。

### 4. 前年繰越残高(期首残高)の管理 — `src/lib/openingBalance.ts`

暗号資産・株式等とも、複数年にまたがって保有している場合の期首残高を
`/import` 画面から登録できる。銘柄ごとに手入力するほか、「{前年}年分の
期末残高から繰り越す」ボタンで前年分の取引から期末残高を自動計算し、
当年分の期首残高として一括登録できる(既存の登録は上書きされる)。
株式等はNISA口座・課税口座を別ロットとして繰り越す。

### 5. 配当所得の課税方式シミュレーション — `src/lib/investment/dividendTaxSimulation.ts`

上場株式等の配当所得について、総合課税・申告分離課税・申告不要のどの方式を
選ぶと税負担が最も軽くなるかを試算する(ダッシュボードの「配当所得の課税方式を
シミュレーションする」から利用)。配当以外の課税所得金額や、損益通算できる
上場株式等の譲渡損失額を入力すると、方式ごとの国税・住民税の試算額と、
配当控除額・損益通算に使った損失額を比較表示する。所得税は速算表による
超過累進税率、住民税は10%固定(均等割は含まない)で計算する概算値であり、
配当控除率は上場株式(普通配当)を前提とする(投資信託等の分配金は控除率が
異なるため、複数銘柄が混在する場合は概算として扱うこと)。

### 6. 確定申告書作成コーナー向け下書きCSV出力 — `src/lib/etax/`

暗号資産・投資の年間集計を、申告書の該当欄と対応付けたCSVとして
ダウンロードできる(ダッシュボードの「下書きCSVをダウンロード」ボタン)。

**重要な制約:** 個人が保有するマイナンバーカードでe-Taxへ電子署名・送信する
処理は、国税庁の「確定申告書等作成コーナー」または「e-Taxソフト」経由でしか
行えない。第三者ツールが認証情報を代行してe-Taxへ直接送信する公式なAPIは
存在しないため、本ツールはe-Taxへの自動送信は行わない。出力されるCSVは
あくまで「確定申告書等作成コーナー」に転記する際の下書き・集計資料であり、
国税庁公式のインポート形式ではない。

## データモデル

`prisma/schema.prisma` を参照。主なテーブル:

- `TaxYear` — 課税年度(暦年)単位でデータを区切る
- `CryptoTrade` — 暗号資産の取引明細
- `InvestmentTrade` — 株式・投資信託等の取引明細(口座区分・NISA区分を保持)
- `ImportBatch` / `CashflowEntry` — マネーフォワード等からの取り込みバッチと明細

## ロードマップ(次回以降のブラッシュアップ候補)

優先度が高いと思われる順:

1. **暗号資産取引所CSVの実データ検証・エイリアス拡充** — `exchangeCsv.ts` は
   実際の取引所ごとの正確な列見出しをまだ十分に検証できていないため、実際に
   エクスポートしたCSVで動作確認し、一致しない列見出しがあればエイリアスを
   追加する。また、暗号資産同士の交換(TRADE_IN/TRADE_OUT)・マイニング等の
   受取(INCOME)のCSV取り込みにも対応する(現状は円建ての現物売買のみ)。
2. **証券会社の特定口座年間取引報告書との突合** — 特定口座(源泉徴収あり)は
   通常確定申告不要だが、他の口座と損益通算・繰越控除したい場合は申告が必要。
   証券会社が発行する年間取引報告書のCSV/PDFを取り込み、本ツールの計算結果と
   突合できるようにする。
3. ~~**移動平均法(暗号資産)への対応**~~ — 対応済み。課税年度ごとに
   `TaxYear.cryptoCostMethod` で総平均法/移動平均法を選択できる
   (ダッシュボードの「暗号資産の評価方法」から変更可能)。
4. ~~**配当所得の課税方式シミュレーション**~~ — 対応済み。
   `src/lib/investment/dividendTaxSimulation.ts` と `/dividend-simulation`
   ページから、総合課税/申告分離課税/申告不要の税額試算・比較ができる。
5. **損失の繰越控除** — 上場株式等の譲渡損失の3年間繰越控除に対応する。
   現状は配当所得シミュレーションの入力欄に損益通算可能な損失額を手入力する
   形にとどまっており、繰越損失そのものをDBで管理・自動計算する機能は無い。
6. **マネーフォワードの資産推移データ(暗号資産・証券口座の残高)を用いた
   取引漏れ検出** — 家計簿CSVだけでなく資産データも取り込み、
   手入力した暗号資産・投資取引の残高と付き合わせて計上漏れを検知する。
7. **認証・マルチユーザー対応** — 現状は単一ユーザーのローカル利用を想定。
   将来的にホスティングする場合はログイン機能が必要。

### 完了済み

  「前年の期末残高から自動で繰り越す」ボタン)。
- **暗号資産の移動平均法対応**(`TaxYear.cryptoCostMethod` と

## 免責事項

本ツールは税額計算を補助するための個人開発ツールであり、税務署・国税庁の
公式ツールではない。計算結果の正確性を保証するものではなく、実際の申告内容は
必ず国税庁「確定申告書等作成コーナー」の計算結果や、税理士等の専門家の確認を
受けること。
